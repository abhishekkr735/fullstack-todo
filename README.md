# Fullstack Todo App

## Learning Outcomes
- Learned Express.js backend
- Implemented CRUD operations
- Understood REST API (GET, POST, PUT, DELETE)
- Used JSON request handling

## Features
- Add Todo
- View Todos
- Update Todo
- Delete Todo

## How to Run
1. Go to server folder
2. Run: npm install
3. Run: node index.js
4. Open: http://localhost:5000
